# Random-Password-Generator-
GUI-приложение «Random Password Generator» с возможностью настройки параметров пароля, сохранением истории и Git.
# Random Password Generator

**Автор:** [Джаппуев Тимур]

## Описание
Простое графическое приложение на Python (Tkinter) для генерации надежных паролей. 
Позволяет настраивать длину, использовать различные наборы символов и сохраняет историю последних 20 паролей в JSON-файл.

## Требования
- Python 3.x
- Библиотека Tkinter (обычно идет в комплекте с Python)

## Как запустить
1. Склонируйте репозиторий: `git clone <ссылка>`
2. Запустите скрипт: `python main.py`

## Примеры использования
- Установите ползунок на 16 символов.
- Отметьте "Цифры" и "Буквы".
- Нажмите "Сгенерировать". 
- Пароль отобразится в поле ввода и сохранится в таблице истории ниже.
